# Neighbor Thermostat

Share one Nest thermostat, not your Google Home. A lightweight, self-hosted app in development.

Runs disconnected until the owner completes setup. No real device commands, payments, or Google grants are performed by installing this project. Google Device Access setup is optional until you are ready; the one-time registration fee is documented separately.

## Development

Requires Node.js 24. Run `npm ci`, then `npm run dev`. Open `http://localhost:3000`.

`npm run check` runs strict TypeScript checks and the test suite.
